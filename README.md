# Fichas de Ameaça T20

Extensão para criar, organizar e consultar fichas de ameaça de Tormenta20 no Owlbear Rodeo 2, com visualização diagramada e biblioteca própria.

## Principais recursos

- Editor completo com salvamento automático e validação dos campos.
- Visualização diagramada, adaptada a fichas curtas ou extensas.
- Biblioteca com busca, duplicação, importação e exportação em JSON.
- Suporte a ataques, habilidades, sub-habilidades, perícias, qualificadores e formatação de texto.
- Uso local sem conta e sincronização opcional entre dispositivos.
- Interface compatível com computador e celular.

## Instalação

No gerenciador de extensões do Owlbear Rodeo, adicione uma extensão usando este manifesto:

`https://demonrider0.github.io/fichas-de-ameaca-t20/manifest.json`

Depois da instalação, abra **Fichas de Ameaça T20** pelo menu de extensões da sala.

## Uso básico

Crie uma ficha pela biblioteca, preencha os campos e retorne à biblioteca quando terminar. As alterações são salvas automaticamente. Abra uma ficha para consultar a versão diagramada ou use o botão de edição para modificá-la.

## Sincronização e uso local

A extensão funciona sem conta e mantém as fichas no dispositivo. Para acessar a mesma biblioteca em outros dispositivos, entre com seu e-mail e confirme o código de acesso recebido. A exportação em JSON permite guardar uma cópia independente da biblioteca.

## Privacidade

Consulte a [Política de Privacidade](https://demonrider0.github.io/fichas-de-ameaca-t20/privacidade.html) para saber quais dados são tratados quando a sincronização é utilizada.

## Compatibilidade

Compatível com o Owlbear Rodeo 2 em navegadores modernos de computador e celular.
